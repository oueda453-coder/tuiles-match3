Règles du jeu

Marché aux tuiles est un jeu de tuiles à assortir, gratuit et jouable sur téléphone comme sur ordinateur.

Le but

Faire disparaître toutes les tuiles du plateau en les regroupant par trois.

Comment jouer

  1. Touchez une tuile libre, c'est-à-dire qui n'est recouverte par aucune autre. Les tuiles assombries sont encore bloquées.
  2. La tuile se place dans le plateau de 7 cases en bas de l'écran.
  3. Quand trois tuiles identiques sont côte à côte, elles disparaissent.
  4. Le niveau est réussi quand il n'y a plus de tuiles sur le plateau.

Quand perd-on ?

Si les 7 cases sont occupées sans qu'aucun groupe de trois ne soit formé, la partie est perdue. Vous pouvez alors réessayer le niveau.

Les boutons

  • Annuler : reprend la dernière tuile placée dans le plateau.
  • Mélanger : redistribue les fruits sur les tuiles restantes, sans changer leur position.

Les niveaux

À chaque niveau, le nombre de tuiles, de couches empilées et de types de fruits augmente. Votre niveau est enregistré dans votre navigateur.
