À propos

Marché aux tuiles est un petit jeu de réflexion gratuit, conçu pour passer quelques minutes agréables sur téléphone ou ordinateur. Il est financé par la publicité afin de rester gratuit pour tous les joueurs.

Les règles s'inspirent des jeux d'assortiment de tuiles classiques. Les visuels et le code du jeu sont originaux.

Une idée, un problème ou une remarque ? Rendez-vous sur la page Contact.
